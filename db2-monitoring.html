Monitoring & Alerting

Core Monitoring Query

SELECT HADR_ROLE, HADR_STATE, HADR_SYNCMODE, HADR_CONNECT_STATUS,
       STANDBY_LOG_GAP, STANDBY_REPLAY_DELAY,
       PRIMARY_LOG_TIME, STANDBY_LOG_TIME,
       HADR_HEARTBEAT
FROM TABLE(MON_GET_HADR(NULL)) AS T;

HADR States Reference

StateMeaning
PEERNormal operation — primary and standby fully synchronised
DISCONNECTEDNo TCP connection between primary and standby
REMOTE_CATCHUPStandby reconnected and catching up with log gap
LOCAL_CATCHUPNew primary catching up after takeover
CONNECTEDTransitional state during startup

Automation — Nagios / Prometheus Example

#!/bin/bash
# check_hadr_state.sh — returns CRITICAL if not PEER
STATE=$(db2 -x "SELECT HADR_STATE FROM TABLE(MON_GET_HADR(NULL)) AS T" | tr -d ' ')
if [ "$STATE" != "PEER" ]; then
  echo "CRITICAL: HADR_STATE=$STATE"
  exit 2
fi
echo "OK: HADR_STATE=PEER"
exit 0
