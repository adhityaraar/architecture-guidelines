Recovery Procedures

Conductor Failover

pcs status                                              # check cluster state
pcs resource move ds-conductor-vip <standby_node>      # manual failover
./dsenv && bin/uv -admin -start                        # restart engine services

Failed Job Recovery

dsadmin -domain <domain> -user <admin> -password <pwd> -listjobs <project>
dsjob -run -mode RESTART -project <project> -job <jobname>  # from checkpoint
dsjob -run -mode RESET   -project <project> -job <jobname>  # force reset state

Repository Recovery (CP4D / Patroni)

oc exec -n <namespace> <patroni-leader-pod> -- \
  patronictl failover --master <current-leader> --candidate <new-leader> --force

For Db2-backed repositories follow the Db2 HADR failover procedure.
