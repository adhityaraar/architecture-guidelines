Parallel Engine Resilience

Failure ScenarioBehaviourAction Required
Worker node crash during jobJob aborted with error codeRe-trigger job from last checkpoint
Worker node removed (planned)In-flight partitions drainedReduce partition count or add replacement before removal
Active conductor crashStandby conductor promoted; in-flight jobs abortedRestart jobs; investigate conductor logs
Shared filesystem unavailableAll jobs failRestore HA filesystem
Repository DB unavailableJob scheduling blocked; running jobs unaffectedTrigger DB failover
Design Jobs for Restartability Always design DataStage jobs to tolerate a restart from a known-good point. Use surrogate key lookup stages idempotently and mark intermediate files as persistent.
