Db2 HADR Pre-Production Checklist

  • Topology selected and sync mode confirmed against tier RPO target
  • Dedicated HADR NIC configured on both primary and standby nodes
  • No shared storage between primary and standby confirmed
  • Active log sized to cover ≥ 1 hour of peak log generation
  • Log archive path configured, tested, and verified on both nodes
  • HADR parameters set correctly on both nodes (LOCAL/REMOTE swapped)
  • HADR started and HADR_STATE = PEER confirmed under load
  • ACR alternate server configured on all client nodes
  • Automation layer (TSA / PowerHA / Pacemaker) configured and tested
  • HADR link encrypted with TLS 1.2+ (mandatory for WAN links)
  • Reads on Standby tested if enabled
  • Graceful takeover tested and RTO measured against target
  • Forced takeover tested and old-primary re-integration verified
  • Monitoring alerts configured and tested end-to-end
  • Db2 Audit enabled with logs retained ≥ 90 days
  • Runbook reviewed and stored in accessible location
