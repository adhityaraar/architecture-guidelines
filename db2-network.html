Network & Storage

Dedicated HADR Interface Required Always use a separate NIC for HADR log shipping — isolated from the client-facing interface. Never bind to 0.0.0.0.

Network Requirements

ParameterRequirementNotes
HADR_LOCAL_HOSTDedicated replication IPNever 0.0.0.0
HADR_LOCAL_SVC / HADR_REMOTE_SVCDedicated TCP port (e.g. 51000)Must match on both ends
Bandwidth (SYNC)≥ peak log rate × 1.5Provision for burst
Bandwidth (ASYNC WAN)≥ avg log rate × 1.2—
Latency (SYNC)< 5 ms RTTSame DC or dedicated interconnect
Latency (ASYNC)< 100 msHigher latency = larger log gap

Storage Requirements

No Shared Storage Do NOT share storage between primary and standby. HADR is log-based; shared disks create a single point of failure.
ComponentRequirementRationale
Database filesIndependent per nodeNo shared-disk dependency
Archive log pathSame logical path on both nodesRequired for log-gap catchup
Active log pathFast storage (NVMe/SSD)Directly affects SYNC commit latency
Standby layoutIdentical tablespace layout to primaryRestore of primary backup initialises standby
