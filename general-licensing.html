IBM IPLA Licensing — Cold, Warm & Hot Standby

When does a backup/standby installation require a separate IBM software licence?

Standby Definitions

TypePrimary CopyBackup Copy"Doing Work"?Licence Required?
ColdRunningNot running (switched off)NoNo
Warm (not doing work)RunningRunning / idlingNoNo
Warm (doing work)RunningRunningYes — e.g. continuous replicationYes
HotRunningRunningYes — actively shadowing primaryYes
Key Rule: Continuous Data Replication = "Doing Work" If the backup copy receives real-time/continuous data replication (e.g. Db2 HADR SYNC or NEARSYNC), the installation is considered to be doing work — even if it is not actively serving user requests. A licence is required for that backup copy.

What Counts as "Doing Work"?

  • Production, development, program maintenance, or testing workloads.
  • Mirroring transactions, updating files, or synchronising programs, data, or other resources.
  • Maintaining an active link, heartbeat, or duplexed/mirrored connection with the primary.
  • Any activity that enables an active hot-switch or synchronised switchover to occur.

DR Testing Allowances

Test TypeDescriptionAllowance (no extra licence)
Backup TestingVerify backup facilities work; primary continues running.1–3 tests per year, each 2–3 days.
DR TestingSimulate a real disaster — primary goes offline, backup takes primary role.1–3 tests per year, each ~2–3 days.
